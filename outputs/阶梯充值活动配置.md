# 阶梯充值活动配置（260924）

更新日期：2026-10-15。

## 本次调整说明（2026-10-14）

本次调整在原阶梯充值功能基础上，统一支持首充、指定次数范围充值及笔笔送。正文以 **【本次新增】**、**【本次调整】** 标记变更点；未标记内容沿用原需求。

| 标记 | 调整项 | 本次要求 |
|---|---|---|
| 【本次调整】 | 适用充值次数 | 「第几次充值」改为「从第几次充值、到第几次充值」，支持次数范围 |
| 【本次新增】 | 参与条件中的充值次数 | 新增「充值次数起始、充值次数结束」，表示本次充值前累计成功充值次数 |
| 【本次新增】 | 笔笔送 | 次数结束值 -1 表示正无穷；首充、范围充值、笔笔送统一配置 |
| 【本次新增】 | **【本次新增】** 奖励类型 | 奖励前增加下拉框：固定金额、比例；比例奖励按本次实际充值金额 × 百分比计算 |
| 【本次调整】 | **【本次调整】** 弹窗默认展示 | 原「是否默认」改为「弹窗默认展示」，由每行否／是改为同一阶梯内跨行单选 |
| 【本次移除】 | 充值页默认展示 | 删除该列及对应保存参数，最终仅保留弹窗默认展示单选 |
| 【本次调整】 | 条件区域名称 | 「条件配置」改为「用户参与条件」 |
| 【本次调整】 | 金额条件字段名称 | 「充值区间起始、充值区间结束」改为「充值金额开始、充值金额结束」 |

## 需求范围

后台：运营工具 → 活动模块 → 活动管理。

前台：APP 首页充值活动弹窗、充值页面赠金展示及选择。

新增「阶梯充值」活动类型，按账号累计成功充值次数配置不同奖励。每个阶梯独立维护充值金额区间、奖励、宣传文案、弹窗展示、打码倍数及参与条件。

## 页面流程

1. 在活动列表点击「创建」，填写通用活动信息，活动类型选择「阶梯充值」。
2. 创建页包含包 ID、分包 ID、活动名称、活动类型、分类、图片、跳转方式、弹窗顺序、排序、状态、展示起止时间、有效起止时间、展示类型、简介、活动参数及活动条件。
3. 创建成功后返回活动列表，在阶梯充值活动的操作列直接展示「编辑规则」按钮。
4. 点击「编辑规则」进入独立规则编辑页，页头展示活动 ID 和活动名称。
5. 保存规则后返回列表，再次进入时回填已保存配置；「返回列表」不保存未提交修改，「重置」恢复进入编辑页时的配置。

## 阶梯配置

### 阶梯页签

- 顶部按显示顺序展示「阶梯 1、阶梯 2……」页签，每次展开一个阶梯。
- 支持新增、删除阶梯，阶梯数量不固定为三个；新增后自动进入新阶梯。
- 切换页签保留已填写内容，删除一个阶梯不改变其他阶梯配置的充值次数。
- 页签编号用于区分配置；业务匹配使用「从第几次充值、到第几次充值」字段。

### 阶梯字段

| 字段 | 输入方式 | 配置规则 |
|---|---|---|
| **【本次调整】** 从第几次充值、到第几次充值 | 整数范围 | 本次充值序号范围，两端均包含；起始至少为 1，结束可填 -1 表示正无穷，各阶梯范围不可重叠 |
| 宣传文案 | 文本 | 每个阶梯独立配置，只填写宣传文字，不填写奖励金额 |
| 充值配置 | 可增删表格 | 按金额区间配置奖励及展示选项 |
| 打码倍数 | 非负数字 | 每个阶梯配置一个倍数，本金与礼金共用；必填，空值不视为 0 |
| 弹窗 | 文本 | 配置弹窗标识 |
| **【本次新增】** 充值次数起始、充值次数结束 | 整数范围 | 本次充值前已完成的成功充值次数，两端均包含；起始至少为 0，结束可填 -1 表示正无穷 |
| **【本次调整】** 充值金额开始、充值金额结束 | 非负整数范围 | 独立的参与条件字段，沿用现有条件口径，与「从第几次充值、到第几次充值」分别保存 |
| 目标用户 | 文本 | 用户 ID 用分号分隔，不填表示全部 |
| 同设备限制 | 非负整数 | 沿用现有设备限制规则 |

### 用户参与条件【本次调整】

该区域标题为“用户参与条件”，包含充值次数起始、充值次数结束、充值金额开始、充值金额结束、目标用户及同设备限制。

### 充值配置表

表格上方提供「添加充值区间」按钮。列顺序如下：

| 列名 | 输入方式 | 配置规则 |
|---|---|---|
| 最小金额（₹） | 金额 | 区间下限，包含该值 |
| 最大金额（₹） | 金额 | 区间上限，不包含该值 |
| **【本次新增】** 奖励类型 | 下拉选择 | 固定金额、比例 |
| **【本次调整】** 奖励（金额 / %） | 非负数字 | 固定金额时填写赠金金额；比例时填写百分比，10 表示 10% |
| 是否在弹窗显示 | 否／是单选 | 控制该行是否在充值活动弹窗中展示 |
| **【本次调整】** 弹窗默认展示 | 单个单选按钮 | 同一阶梯内各行共用一组，最多选择一行 |
| 操作 | 移除按钮 | 删除当前行 |

- 每个阶梯至少配置一个金额区间。
- 区间匹配方式为 **最小金额 ≤ amount < 最大金额**，即 `[min, max)`。
- 同一阶梯内区间不得重叠，相邻区间可共用边界。
- 金额和奖励为非负数，最多支持两位小数，最小金额必须小于最大金额。
- 「是否在弹窗显示」仍为每行独立的否／是选择，新增行默认“否”。
- **【本次调整】** 弹窗默认展示每行设置一个单选按钮；同一阶梯选择另一行会取消原选中行，不影响其他阶梯。新增行默认不选中。
- 「是否在弹窗显示」仅控制展示，不改变奖励金额、金额匹配及领取条件。
- 默认展示不代替用户主动选择参与活动。

## 金额匹配与奖励领取

1. 充值次数按账号累计成功充值次数计算，失败订单不计次。
2. **【本次调整】** 本次充值对应次数 = 已完成成功充值次数 + 1，使用该次数匹配阶梯的充值序号范围，同时校验充值前已完成次数是否满足条件中的充值次数范围。
3. 使用适用充值配置中的 amount 匹配当前阶梯的金额区间。
4. 只有属于适用充值配置、且命中当前阶梯区间的 amount 才展示对应赠金。
5. **【本次调整】** 用户主动选择赠金活动后，该笔充值成功才能领取对应奖励。固定金额直接取配置值；比例奖励 = 本次实际充值金额 × 配置比例 ÷ 100。比例金额的精度及舍入沿用现有奖励结算规则。
6. 次数未配置、金额不属于充值配置、金额未命中区间、未选择参与活动或充值失败时，不发放该活动奖励。
7. 打码要求 =（本次充值本金 + 领取礼金）× 当前阶梯打码倍数。

## 宣传文案展示

后台配置纯文字，前端根据所选充值金额匹配到的奖励拼接金额。

```text
宣传文案：First deposit bonus up to
充值金额：₹300
对应奖励：₹100
展示内容：First deposit bonus up to +₹100
```

- 切换充值金额后，奖励金额随匹配结果更新。
- 不固定展示整个阶梯的最高奖励。
- 各阶梯使用各自的宣传文案，支持保存、回填和重置。

## 首页充值弹窗

登录 APP 进入首页时，按下一次充值是否配置了奖励判断弹出资格，并匹配弹窗样式。活动状态、展示时间、有效时间及弹出频率沿用活动通用配置。

| 用户状态及配置 | 首页弹出内容 | 样式 |
|---|---|---|
| 尚未完成首充，配置了第 1 次充值奖励 | 第 1 次充值活动 | 样式一 |
| 已完成首充，下一次充值配置了奖励 | 下一次充值对应的活动 | 样式二 |
| 下一次充值未配置奖励 | 不弹出本阶梯充值活动 | — |

后续充值活动必须在完成前面的充值次数后才能触发，不提前展示尚未轮到的阶梯。弹窗内金额区间按「是否在弹窗显示」配置展示。

### 不连续充值次数示例

仅配置第 1 次、第 3 次充值奖励时：

| 已完成成功充值次数 | 下一次充值 | 活动配置 | 首页弹窗 |
|---:|---:|---|---|
| 0 | 第 1 次 | 有 | 第 1 次活动，样式一 |
| 1 | 第 2 次 | 无 | 不弹出本活动 |
| 2 | 第 3 次 | 有 | 第 3 次活动，样式二 |
| 3 | 第 4 次 | 无 | 不弹出本活动 |

```text
未完成首充 → 登录 APP 弹出第 1 次活动（样式一）
完成第 1 次 → 第 2 次未配置活动，不弹出本活动
完成第 2 次 → 登录 APP 弹出第 3 次活动（样式二）
```

第 2 次充值失败时，累计成功次数仍为 1，不满足第 3 次活动的弹出条件。

## 充值次数范围配置【本次新增】

首充、指定次数范围充值和笔笔送均通过阶梯充值活动配置。

| 场景 | 从第几次充值 | 到第几次充值 | 条件充值次数起始 | 条件充值次数结束 |
|---|---:|---:|---:|---:|
| 首充 | 1 | 1 | 0 | 0 |
| 第 2 至第 5 次充值 | 2 | 5 | 1 | 4 |
| 第 6 次起笔笔送 | 6 | -1 | 5 | -1 |

- 上方范围表示本次充值是第几笔；条件充值次数表示本次充值前累计成功充值的笔数。
- 两个范围的有限端点对应相差 1：条件起始 = 上方起始 − 1，条件结束 = 上方结束 − 1。
- `-1` 仅用于次数范围的结束值，前后端统一约定为正无穷；上方结束为 -1 时，条件结束同为 -1，不做减 1 运算。
- 次数范围为闭区间；金额范围继续采用 `[最小金额, 最大金额)`，两种范围的边界规则分别处理。
- 未配置的次数不享受活动，笔笔送范围内每一笔成功充值均可按规则参与；失败订单不推进次数。
- 首页根据下一次充值序号匹配范围；第 1 次使用样式一，第 2 次及以后使用样式二，跳次规则不变。
- 保存时校验两个次数范围的对应关系；无上限阶梯不能与后续其他范围重叠。

## 金额奖励示例

以下为固定金额奖励示例，实际次数范围、金额区间、奖励类型及奖励均由运营配置。

| 金额区间（₹） | 第 1 次奖励（₹） | 第 2 次奖励（₹） | 第 3 次奖励（₹） |
|---|---:|---:|---:|
| [0, 100) | 7 | 3 | 3 |
| [100, 200) | 20 | 10 | 7 |
| [200, 300) | 45 | 37 | 17 |
| [300, 500) | 100 | 50 | 37 |
| [500, 1000) | 200 | 100 | 77 |
| [1000, 2000) | 500 | 177 | 100 |
| [2000, 3000) | 750 | 277 | 177 |
| [3000, 5000) | 1500 | 377 | 277 |

第 1 次充值时，amount=300 命中 `[300, 500)`，奖励 100；amount=500 命中 `[500, 1000)`，奖励 200。金额即使落入区间，仍须存在于适用充值配置中才展示赠金。

## 验收标准

1. 创建活动后，可从列表操作列进入独立规则编辑页。
2. 阶梯可增删、切换；配置超过三个阶梯时仍可正常保存。
3. **【本次调整】** 次数范围须为整数，起始分别至少为 1 和 0；结束为 -1 或不小于起始，各阶梯本次充值次数范围不可重叠，页签排序不影响匹配。
4. 区间为空、最小值不小于最大值、区间重叠、金额格式错误时阻止保存，并定位对应阶梯。
5. 共用边界值命中以该值为最小金额的行，不命中以该值为最大金额的行；金额等于最后一个区间的最大值时，不命中该区间。
6. **【本次调整】** 表格按最小金额、最大金额、奖励类型、奖励、是否在弹窗显示、弹窗默认展示、操作排列；弹窗默认展示在同一阶梯内单选，保存后正确回填。
7. 宣传文案按阶梯保存；前台拼接所选充值金额对应的奖励，切换金额后正确更新。
8. **【本次调整】** 打码倍数须为有效非负数；条件充值金额开始值不得大于结束值，同设备限制须为非负整数。
9. 未配置次数、未匹配金额、未选择赠金或充值失败时，不发放活动奖励。
10. 未完成首充且配置了首充奖励时，首页使用样式一；完成首充且下一次充值配置了奖励时，使用样式二。
11. 仅配置第 1、3 次奖励时，完成第 1 次后不提前弹出第 3 次；完成第 2 次后才弹出第 3 次活动，使用样式二。
12. 保存后再次进入，全部字段正确回填；返回列表不保存草稿，重置恢复进入页面时的配置。
13. **【本次调整】** 固定奖励 20 时发放 20；比例奖励填 10、实际充值 300 时奖励为 30。
14. **【本次调整】** 1–1 对应条件 0–0，2–5 对应 1–4，6–-1 对应 5–-1；完成 5 次充值后，第 6 次及其后续充值匹配笔笔送。
15. **【本次调整】** 次数结束为 -1 时可保存、回填和重置；其他负数、倒置范围、范围重叠及上下条件不对应时阻止保存。
